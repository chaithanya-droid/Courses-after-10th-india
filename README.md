# Courses After 10th India 🌸 **Explore your future. Discover the right course after Class 10.** Courses After 10th India is a simple, mobile-friendly website that helps students explore different education and career pathways available after completing Class 10 in India. ## ✨ Features - Browse Intermediate streams such as MPC, BiPC, CEC, MEC and HEC. - Explore Diploma and Polytechnic course options. - Discover ITI trades and skill-based courses. - Explore creative and healthcare-related study options. - Search courses by name, subject or career area. - Filter courses by category and duration. - Clean Sakura-inspired design with soft, transparent cards. - Responsive layout for mobile phones, tablets and computers. ## 🛠️ Built With - HTML5 - CSS3 - JavaScript No frameworks or installation are required. ## 🚀 Run the Website 1. Download or clone this repository. 2. Open the `index.html` file in a web browser. ## 🌐 Deploy with GitHub Pages 1. Open your repository on GitHub. 2. Go to **Settings → Pages**. 3. Under **Build and deployment**, choose **Deploy from a branch**. 4. Select the `main` branch and `/ (root)` folder. 5. Save and wait for GitHub Pages to publish your website. Your published website URL will be shown in the GitHub Pages settings. ## 🎯 Purpose The purpose of this project is to make it easier for students and parents to explore education options after Class 10 and learn about possible next steps. ## ⚠️ Important Notice Course availability, eligibility, duration, admission procedures and recognition can vary by state, institution and academic year. Always confirm current information with the relevant official education board, admission authority or institution before applying. This website is an educational information guide and is not an admission authority. ## 🤝 Contributions Suggestions and improvements that make the website more useful for students are welcome.
